# Job Supply & Skill Insights

*Developed by Ritu Raj Singh*

## Project Overview

This project analyzes job posting activity and skill requirements to understand job supply, posting trends, company activity, job status, and skill threshold performance.

The objective is to create reliable, decision-focused metrics that help understand how jobs are being posted and how skill thresholds are being used.

## Objectives

* Analyze overall job supply
* Identify active, closed, and draft jobs
* Understand job distribution across locations
* Analyze job demand by job title
* Track monthly job posting trends
* Analyze skill threshold requirements
* Monitor job-posting event success
* Create a decision-focused Tableau dashboard

## Tools & Technologies

* *Excel* – Data cleaning and preparation
* *Python / Pandas* – Data analysis
* *Tableau* – Data visualization and dashboard
* *GitHub* – Project documentation and version control

## Data Cleaning

The raw dataset was cleaned using *Microsoft Excel*. The cleaning process included handling missing values, duplicate records, inconsistent text values, incorrect data formats, and invalid values.

The cleaned dataset was then used for Python analysis and Tableau visualization.

## Analysis Performed

The Python analysis covered:

* Total jobs and companies
* Job status distribution
* Job supply by location
* Job supply by company
* Job title analysis
* Monthly job posting trends
* Event status and success rate
* Source-system analysis
* Skill threshold analysis
* Experience requirements
* Salary analysis
* Company and location comparisons

All analysis outputs were consolidated into a single *Python Analysis Result* workbook.

## Tableau Dashboard

The final Tableau dashboard provides a simple view of:

* Total Jobs
* Total Companies
* Active Jobs
* Average Salary
* Average Minimum Skill
* Job Supply by Location
* Jobs by Job Title
* Job Status
* Monthly Job Supply
* Skill Threshold Distribution

## Key Outcome

The project provides a clear view of job supply and posting activity while connecting important metrics with practical business decisions. It also demonstrates an end-to-end data analytics workflow from Excel data cleaning to Python analysis and Tableau visualization.
